# v3.9.5 — Stable feature selection

- Disabled mouse drag, wheel zoom, touch pinch and double-click zoom on the feature map. Zoom remains available through the + / - controls.
- Disabled automatic map panning when a popup opens.
- Switched to SVG feature hit detection and enlarged visible point markers.
- Added invisible 24-pixel clickable hit areas over ocean feature boundaries.
- Preserved GPS coordinate popups, copy button, bank selection, map overlays, map bounds, generation, and history workflow.
- No changes to numerical feature detection, forecast API calls or stored history.

Note: Test browser behaviour after deployment. This release does not assert live-browser verification.
